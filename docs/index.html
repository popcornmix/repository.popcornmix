popcornmix Add-ons

A Kodi add-on repository. It currently carries inputstream.airplay, an AirPlay receiver for screen mirroring, video streamed from apps, and audio.

Download repository.popcornmix-2.0.0.zip

Installing on LibreELEC

  1. Copy the zip above to the machine running Kodi — over the network, or onto a USB stick.
  2. In Kodi, go to Settings → System → Add-ons and turn on Unknown sources.
  3. Settings → Add-ons → Install from zip file, and pick the zip.
  4. Install from repository → popcornmix Add-ons → VideoPlayer InputStream, and install AirPlay Receiver.

Kodi serves the build matching its own version and architecture, and updates the add-on from here as new builds are published.
